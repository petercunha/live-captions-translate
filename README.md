# Live Captions & Translate

A Chrome extension that captions whatever a tab is playing (videos, meetings,
streams) and translates the captions live. Everything runs on your machine: no
audio or text leaves the browser.

## How it works

```
tab audio ─► offscreen document ─► speech recognition ─► Chrome Translator ─► overlay on the page
 (tabCapture)  (keeps tab audible,    Moonshine (WASM, CPU)   (built-in,           + transcript side panel
               resamples to 16 kHz)   or Whisper (WebGPU)      on-device)
```

| Spoken language | Engine | Why |
|---|---|---|
| English | **Moonshine Streaming** Small (default), Tiny or Medium | Built for live captioning: true streaming, ~0.2 s update latency, ~0.7 CPU cores. Small (123M params) is more accurate than Whisper Small on the Open ASR benchmarks at half the size. |
| Spanish, Chinese, Japanese, Korean, Arabic, Ukrainian, Vietnamese | Moonshine per-language models | Small dedicated models, same pipeline. Downloaded from the Moonshine CDN on first use, then cached. |
| Auto-detect, or 25 other languages | **Whisper Small** on WebGPU | Covers ~100 languages. Moonshine's voice detector cuts the audio into utterances, so Whisper only runs on speech, mostly on the GPU. |

**Translation** uses Chrome's built-in [Translator API](https://developer.chrome.com/docs/ai/translator-api)
(on-device, same models as Chrome's page translation). It is fast and needs no
extra download in the extension. In auto-detect mode, Chrome's on-device
`LanguageDetector` checks the transcribed text so the right language pair is used.

### Measured on an M1 Max (Chrome 155)

| Mode | CPU (whole browser, while captioning) | Model size |
|---|---|---|
| Chrome just playing the audio | ~0.1 core | n/a |
| English, Moonshine Small + translation | ~0.8 core | 165 MB |
| English, Moonshine Medium + translation | ~2 cores (measured before the 4-thread cap, so likely less now) | 305 MB |
| Any language, Whisper Small (WebGPU) + translation | ~0.6 core (+GPU) | 410 MB |

## Install

Requires Chrome 138 or newer and Node 18+.

1. `npm install && npm run setup`. This vendors the runtimes and downloads the
   models, about 1 GB. Model files aren't in the repo; `node scripts/fetch-models.mjs`
   with no arguments fetches only Moonshine Small and Whisper Small, and anything
   missing downloads on first use.
2. Open `chrome://extensions`, turn on **Developer mode** (top right)
3. Click **Load unpacked** and pick the `extension/` folder

## Use

- Click the toolbar icon on a tab that's playing audio, pick the spoken language
  and the translation target, then press **Start captions**. Or press
  <kbd>⌥⇧C</kbd> (Alt+Shift+C) to toggle captions on the current tab.
- Captions appear over the page: drag to move, double-click to reset, hover for ×
  to stop. They follow the video into fullscreen.
- **Open transcript** shows the whole session in the side panel, with Copy and Save.
- Chrome downloads each translation language pack once. Pressing Start triggers
  that for the chosen pair. In auto-detect mode the overlay offers a
  **Download** button the first time a new language shows up.

## Project layout

```
extension/
  manifest.json
  background.js        service worker: tab capture, session state, message relay
  offscreen.js         audio capture, Moonshine/Whisper engines, translation
  capture-worklet.js   16 kHz resampling AudioWorklet
  whisper-worker.js    Transformers.js Whisper (WebGPU) worker
  lib/whisper-core.js  Whisper + spoken-language detection
  content.js           caption overlay (shadow DOM)
  popup.*, sidepanel.* UI
  shared/languages.js  languages, engines, defaults
  vendor/              generated by `npm run vendor` (gitignored)
  models/              generated by `npm run models` (gitignored)
scripts/
  vendor.mjs           copies + patches runtimes from node_modules
  fetch-models.mjs     downloads models (`node scripts/fetch-models.mjs medium tiny`, or `all`)
  make-icons.mjs       draws the icons
```

`scripts/vendor.mjs` patches the vendored runtimes in three ways:

- Emscripten's embind glue builds wrappers with `new Function`, which Manifest V3
  forbids. The patch swaps in Emscripten's eval-free closures.
- Moonshine's downloader can't cache `chrome-extension://` URLs. The patch skips
  the cache for bundled files.
- ONNX Runtime's thread pool is capped at 4 threads (30% less CPU).

Each patch asserts it applied, so an upgrade that changes the code fails loudly.

The manifest deliberately doesn't set cross-origin isolation (COOP/COEP). With
it, `tabCapture` streams fail in the offscreen document. Extension pages get
`SharedArrayBuffer` without it anyway.
